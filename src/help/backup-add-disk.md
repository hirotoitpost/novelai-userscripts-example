写し先の空きが足りなくなってきたら、ディスクを足します。今ある写し先のデータを引っ越す必要はありません。

## 手順

![見本: 写し先 Y: を足して、2か所にそろえる](/help-media/backup-add-disk.mp4)

1. 足すディスクをパソコンにつなぎます(外付けドライブなど)
2. ホームの **開発管理者** → **操作とデータ** → [画像・作品データのバックアップ](/admin?tab=ops#data-backup) を開きます
3. **写し先を足す** を押し、増えた欄にフォルダの場所を入れます(例: `F:\backup`)
4. 必要なら **残す空き** を決めます(既定は 50GB か 10% の大きい方。[決め方](/help/backup-threshold))
5. **設定を保存** を押します。写し先に印(`disk.json`)が作られ、空きが表示されます
6. **今すぐバックアップ** を押します

## 足したあとの最初の回

- 足したディスクには空きが多いので、新しい中身はそこに多く入ります
- 置く数か所にそろっていない中身があれば、この回で足したディスクに写してそろえます。**最初の回は時間がかかります**
- 終わったら、各写し先の行に「前の回のとき: 中身 N 個」と出ます。赤い警告が出ていなければ完了です

## 注意

- このアプリと **同じドライブ** のフォルダは避けてください。ドライブが壊れると、元のデータとその写し先を一緒に失います
- 同じドライブの別のフォルダを2つ登録しても、壊れたときの備えにはなりません
- ドライブ文字が変わっても、印で同じディスクだと分かります。別のディスクが同じドライブ文字に来たときは、まちがって使わないよう飛ばします
