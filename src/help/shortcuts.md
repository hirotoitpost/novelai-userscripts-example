PC では、キーボードで操作できます。割り当ては YouTube に合わせています。どのページでも **?** を押すと、一覧が出ます。

文字を入力しているとき(検索欄・プロンプト・メモなど)と、Ctrl・Alt・⌘ と一緒に押したときは効きません。

## どのページでも

- **?**: キーボードショートカットの一覧を出す(もう一度押すか Esc で閉じる)
- **/**: ページの検索欄へ移る(ギャラリー・キャラ一覧・本棚・ヘルプ など)
- **F**: 見ている画像・漫画を全画面にする

**F** は、全画面のボタンがある画面で効きます(ギャラリーの拡大表示、生成した画像の拡大表示、本棚で漫画を読んでいるとき)。

## 画像の拡大表示・本棚で読んでいるとき

- **J** / **←**: 前の画像
- **L** / **→**: 次の画像
- **Home** / **End**: 本棚: 最初のページ / 最後のページ
- **Esc**: 閉じる

本棚の漫画は右から左へ読むので、**←** が次のページ、**→** が前のページです。**J** と **L** は向きに関係なく、**J** が前のページ、**L** が次のページです。

## 全画面のとき

- **F** / **Esc**: 全画面を終える(ズーム中の Esc は、まずズームを戻す)
- **J** / **L**: 前 / 次
- **←** / **→**: 左 / 右の画像(漫画は ← が次のページ)
- **← ↑ → ↓**(ズーム中): 見ている範囲を動かす。**Shift** を押しながらだと大きく動かす
- **+** / **-**: ズームする / 戻す
- **0**: ズームを戻す

ズーム中は、矢印キーが範囲の移動になります。ズーム中に前後の画像へ移るときは **J** / **L** を押してください。ズームを戻すと(Esc か 0)、← / → はまた前後の画像になります。
