ホームの **🔏 見えない透かし** から開きます。

## 何が起きるか

次の画像には、目に見えない透かし(画像ごとの番号)が自動で入り、台帳に残ります。

- **X に投稿** した画像(投稿をやり直しても、同じ画像には同じ番号)
- **出版する** で作った出版物(ZIP)の画像。BOOTH などで配る画像はこちらで作ります

透かしは絵の明るさをごくわずかに変えるだけで、拡大しても見分けはつきません。ベタ塗りの部分には入れません。
NovelAI の生成情報(メタデータ)は、これまでどおり取り除かれます。

## 照合する

ネットで見かけた画像を **照合する** の枠に置く(または押して選ぶ)と、自分の出した画像かを確かめます。

| 結果 | 意味 |
|---|---|
| 出したファイルとまったく同じ | 出した画像そのもの |
| 透かしを読めた | 再圧縮(X の JPEG など)されていても、自分の出した画像 |
| 元の大きさに戻して透かしを読めた | 縮小されていたが、自分の出した画像 |
| よく似た画像を出しています | 透かしは読めないが、見た目の指紋がほぼ同じ(切り抜き・加工されたかもしれない) |
| 見つかりません | 台帳に一致する画像が無い |

## できないこと

- 透かしは **コピーを防ぎません**。見かけた画像が自分のものかを、あとから確かめるためのものです。
- 大きく切り抜いたもの・回転したもの・半分以下に縮めたものは、透かしを読めないことがあります(見た目の指紋で「似ている」とは分かることがあります)。
- 台帳はこのアプリの中だけにあります。別の環境で入れた透かしは読めません。
- 透かしの鍵は `.env` の `WATERMARK_KEY` で変えられます(無ければ既定の鍵)。変えると、それまでの透かしは読めなくなります。

## NFT として記録する(Sepolia テストネット)

台帳の画像を1枚ずつ、イーサリアムのテストネット Sepolia の NFT として記録できます。
「この画像を、この日時に出した」ことを、誰でも見られる形で残すためのものです。

- チェーンに載るのは、ファイルの指紋(SHA-256)・見た目の指紋・出した日時・透かしの番号だけです。画像・題名・X のアカウントは載りません。
- 記録に **お金としての価値はありません**。**譲渡もできません**(契約で止めています)。売り物として扱わないでください。
- テストネットは数年で終わることがあり、ずっと残る保証はありません。

### 準備

1. ブラウザに MetaMask を入れ、**テスト用の別のアカウント**を作ります(本物の資産のあるアカウントは使わない)。
2. MetaMask のネットワークを **Sepolia** にします(「テストネットワークを表示」をオンにすると選べます)。
3. フォーセットでテスト用の ETH をもらいます(例: Google Cloud の Web3 フォーセット。0.05 ETH ほどあれば十分です)。

### 使い方

1. **MetaMask につなぐ** を押します。
2. 初回だけ **記録の契約を作る** を押し、MetaMask で承認します(記録をまとめる「入れ物」を作ります)。
3. **N 枚を発行する** を押し、MetaMask で承認します。1回に 20 枚まで、1回の取引でまとめて発行します。
4. 台帳の **NFT ✓** から、Etherscan(Sepolia)で記録を見られます。照合の結果にも出ます。

アプリは秘密鍵を受け取りません。署名はすべて MetaMask の画面で行います。
Sepolia 以外のネットワーク(本物のイーサリアムなど)では、発行のボタンは動きません。
