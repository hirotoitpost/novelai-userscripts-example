漫画は、**物語(台本)** を **シーン** に分け、1シーンを1コマとして絵を描き、ページに並べて吹き出しと描き文字を入れて作ります。

## 全体の流れ

1. 物語(台本)を用意する
2. シーン(コマ)に分ける・セリフとタグを直す
3. 登場人物をシーンに割り当てる
4. コマの絵を生成する・気に入らないコマを描き直す
5. 効果音・ナレーションを入れる
6. ページを合成し、吹き出しの位置などを整える
7. PDF か画像一式でダウンロードする

できた漫画は **本棚** から読めます。

## 1. 物語を用意する(入口は4つ)

- **物語エディタ**: NovelAI の文章モデルと対話しながら物語を書き、書き上げたら **漫画にする →** で漫画の作業へ進みます
- **漫画ドラフト**: テーマとキャラから大枠を選び、4コマの台本を書き進めます
- **物語 → 漫画** の「1. 前提を入力」: 前提(あらすじ)から **ドラフト生成** でシーンに分けた下書きを作ります
- **物語 → 漫画** の「1b」「1c」: 公式サイトで書いた物語の取り込みや、下着・水着のコレクションの台本づくり

Claude Code に台本を渡して、漫画の物語を作ってもらうこともできます。

## 2. シーン(コマ)を直す

**物語 → 漫画** で物語を開くと **シーン一覧** が出ます。**編集(コマ割り・セリフ・タグ)** で、コマの並べ替え・追加・削除、ページの区切り、セリフ、タグ、登場人物をまとめて直し、上書き保存(または別名保存)します。

## 3〜7. 絵を描いて仕上げる

全部のシーンに本文が入ると、シーン一覧の下に登場人物と漫画の欄が出ます。漫画の作り方で **v2: コマごとに生成(コマ割り・吹き出しは自前)** を選ぶと、コマの絵の生成からダウンロードまでを、その下の欄で行えます。

- [登場人物をそろえる](/help/manga-characters)
- [コマの絵を描く・描き直す](/help/manga-panels)
- [ページを合成して仕上げる](/help/manga-compose)

> もう1つの作り方 **v1: V5でページごと生成** は、ページ1枚を丸ごと絵にします(コマ割り・吹き出しは絵の中)。手軽ですが、セリフや配置は直せません。
