ホームの **💬 対話生成** から開きます。**キャラの生成した画像** の **対話で直す** を押すと、その画像のタグとシードから始められます。作業アシスタントの **チャット** の **対話で描く** からも開けます。漫画のコマは、物語のページの漫画のコマの **💬 対話で描き直す** から開きます(下の「漫画のコマを描き直す」)。

## 流れ

1. 上の **キャラ** のボタンで、キャラを絵で選びます(選ばなくても描けます)。作品(シリーズ)ごとの列に参照画像のカードが並び、押すとプロフィール(年齢・普段の服・出ている作品)が出ます。**このキャラにする** で決まります。上の欄で名前やメモから探せます
2. 左の欄に、描きたい絵を日本語で書いて **送る**(Ctrl+Enter)
3. 文章モデル(NovelAI の GLM-4.6)が場面のタグを考え、右の **場面のタグ** と **ネガティブ** に入れます。変わったタグは色付きで出ます(緑: 足した / 黄: 重みを変えた / 赤: 外した)
4. **このタグで生成** で描きます
5. 「顔が逆さま」「膝を床から離して」「お腹まで入れて」のように直したい所を書くと、前のタグを土台に直します

「このタグの意味は?」のように聞くと、描かずに説明だけします。

## 決まりごと

- 文章モデルが書くのは **場面のタグ** だけです。キャラの見た目・絵柄は、キャラシートからアプリが入れます。**普段の服** にチェックを入れると、キャラシートの服も入ります
- 描くのは **このタグで生成** を押したときだけです。**案が出たらすぐ描く** を入れると、案が出るたびに描きます(そのぶん Anlas を使います)
- **シードを固定** にすると、同じシードで描くので、タグだけを変えた違いを見比べられます
- **キャラ参照** は、キャラシートの参照画像で顔と髪をそろえます(Anlas が増えます)。**強さ** を下げると、絵柄が参照画像に引っ張られにくくなります
- 成人として登録していないキャラ(キャラシートで成人の年齢を入れていないもの)は、性的な場面を描けません
- タグは手で直してもかまいません。次の相談は、直したタグを土台にします

## 描いた絵と会話

- 描いた絵は、ギャラリーと、キャラの **生成した画像** に並びます
- 右の小さい絵を押すと切り替わります。**この絵を土台にする** で、その絵のタグとシードに戻せます
- 会話は自動で残ります。上の一覧から開き直せます。**この会話を消す** で消しても、描いた絵は残ります

## 漫画のコマを描き直す

物語のページの漫画のコマにある **💬 対話で描き直す** で開くと、そのコマの描き直しになります。

- 場面のタグは、シーンの作画タグから始まります。下の欄は **このコマに出てはいけない物** です
- 登場人物の見た目・服、コマの形、カラー/モノクロ、キャラ参照、画像の設定は、ボタンを押したときの漫画のページの設定を使います
- **このタグで候補を描く** で描いた絵は、コマの **候補** に入ります。コマの絵はまだ変わりません
- 気に入った絵で **このコマに採用** を押すと、その絵がコマになり、描いたときのタグがシーンに保存されます(それまでのコマの絵は候補に戻ります)
- 吹き出しを入れ直すには、物語のページで合成し直してください。上の **物語に戻る** で戻れます
