# nerdstash_v2 tokenizer

`nerdstash_v2.model` is NovelAI's official Kayra (`kayra-v1`) tokenizer, copied verbatim from
https://github.com/NovelAI/novelai-tokenizer (`novelai_v2.model`), which NovelAI publishes under
the GNU General Public License v2 (see `LICENSE` in this directory). It is used by
`src/python/novelai_text.py` to encode/decode text for NovelAI's official story-writing API
(`text.novelai.net`).
