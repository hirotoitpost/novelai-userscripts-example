# 作品の取り込み

漫画(PDF・画像・zip)を取り込み、コマ割りとコマごとの内容を読み取って、新しい漫画づくりに使う機能です(`/manga-import`)。

取り込むときに、何のために取り込むか(使い方)を選びます。

| 使い方 | `purpose` | 読み取るもの | 保存するセリフ | できること |
|---|---|---|---|---|
| 似た漫画を作る | `similar`(既定) | コマ割り、構図、人数、場面、所作、セリフの型 | **型だけ**(文字数・文末の型・口調)。文面は保存しない | 似た漫画を作る |
| 自分の作品を作り直す | `rebuild` | 上に加えて、セリフの文面 | 文面とページ上の位置 | 似た漫画を作る、作り直す |
| (構成のみ) | `structure` | コマ割り、構図、人数、セリフの量 | なし | 似た漫画を作る(場面・所作の再現なし) |

`structure` は、使い方を選べるようになる前に取り込んだものです。新しく取り込むときは選べません。「読み取り直す」で `similar` か `rebuild` に変えられます。

## 1. 読み取り

1ページずつ、次の順で読みます([src/python/manga_import.py](../src/python/manga_import.py)、[src/python/manga_reading.py](../src/python/manga_reading.py))。

| 読むもの | 方法 | 備考 |
|---|---|---|
| コマ・顔・体・文字の位置 | 検出モデル(manga109_yolo) | 使えなければ、枠線と頭の検出で代える |
| 人数・構図(寄り/中/引き) | 顔の数と大きさ | |
| 役割・感情 | ローカルの画像モデル(任意。1コマ十数秒) | 「コマの役割・感情も読み取る」をオンにしたとき |
| **セリフ** | RapidOCR でページ全体を読み、列を吹き出しごとにまとめる | 縦書きは右の列から左へつなぐ。`similar` / `rebuild` のとき |
| **場面・所作** | コマを切り出して判定モデル(WD Tagger)にかける | `similar` / `rebuild` のとき |

1ページあたり、セリフと場面・所作の読み取りで十数秒かかります。

### セリフ

- 吹き出しの中の活字が対象です。手描きの効果音(描き文字)はほとんど読めないので、文字の領域の検出に重なる列と、確からしさの高い列だけを残します。
- 「おわり」「つづく」などの印、ページ番号、記号だけの文字は捨てます(「……」「!?」だけのセリフは残します)。
- コマの中では、上の段から、同じ段では右から読みます。
- セリフごとに**型**を作ります: 文字数(`chars`)、文末の型(`ending`: ふつう / 問いかけ / 強い調子 / 言いよどみ)、丁寧な口調か(`polite`)。
- `rebuild` のときだけ、文面(`text`)とページ上の位置(`box`)も保存します。`similar` では、読んだ文面はその場で捨てます。

読み取りの誤りはあります(小さい「っ」や末尾の「!!」が落ちる、効果音が混じる、など)。`rebuild` では、取り込みの画面でコマごとに直せます。

### 場面・所作

判定モデルのタグ(確率 0.45 以上)を、コマごとに3つに分けます。

| 種類 | 中身 | 例 |
|---|---|---|
| 場面(`scene_tags`) | 舞台・小物・時間帯・構図 | `hallway`, `school`, `clock`, `from behind` |
| 所作(`action_tags`) | 表情・動作・人物どうしの関わり | `arm hug`, `blush`, `open mouth`, `one eye closed` |
| 写っている人(`cast_tags`) | 人数と性別 | `1girl`, `1boy` |

髪型・服などの見た目は取りません(キャラシートの側で持つため)。体つき・露出の語を含むタグと性的なタグも使いません。これはコンテンツガードの `similar.excluded_words` と `scene.sexual_tags` で決まります([content_guard_jp.md](content_guard_jp.md) §18)。

## 2. 似た漫画を作る

`POST /api/manga-import/{id}/similar`(取り込みの画面の「似た漫画を作る」)。

1. ページの絵から、舞台と人物の見た目を読む。
2. キャラを決める。選んだキャラがあればそれを使い、無ければ、読み取った見た目から新しいキャラを作る(名前・人物像・足りない髪色などは文章モデルが決める)。参照画像の無いキャラには自動で作る。
3. 大枠シナリオと、1ページ=1話の台本を文章モデルで作る。コマごとに、構図・人数・**場面・所作・セリフの型**を渡す。
4. 台本に、取り込んだコマの場面を写す(`apply_import_panels`)。
5. 取り込んだ作品のコマ割りで物語を作り、コマの絵を生成してページに合成する。

再現するものと、しないもの:

| 再現する | 再現しない(新しく作る) |
|---|---|
| コマ割り、コマ運び(山場・オチの位置) | 話の筋、設定 |
| 構図(寄り/引き、向き) | セリフの文面 |
| 場面(舞台・小物) | キャラそのもの(名前、判定モデルのキャラ名のタグ) |
| 所作(表情・動作・人物どうしの関わり) | |
| セリフの数・長さ・調子 | |

手順4では、文章モデルが入れ忘れても再現されるように、次のことをプログラムで行います。

- 場面のタグを、コマの作画タグ(`prompt_tags`)の先頭に足す。
- 所作のタグが台本のどの人物にも付いていなければ、描く人物が1人のコマではその人に付ける(2人以上のコマは、だれの所作かを文章モデルの割り振りに任せる)。
- セリフの無かったコマは、セリフを空にする。

### セリフのない漫画

セリフを読んだうえで、どのコマにもセリフが無かった作品は「セリフのない漫画」として扱います。大枠と台本の指示に「セリフや説明に頼らず、絵(表情・動作・場面)だけで伝わる話にする」を足し、各コマのセリフは空のままにします。雰囲気は、絵から読んだ場面と所作で再現します。

## 3. 自分の作品を作り直す

`POST /api/manga-import/{id}/rebuild`(取り込みの画面の「作り直す」)。使い方が `rebuild` の取り込みだけで使えます。**自分の作品(権利のある作品)のためのものです。**

1. キャラを決める(似た漫画と同じ)。
2. ページごとに、文章モデルに次のことだけを決めさせる([src/python/manga_rebuild.py](../src/python/manga_rebuild.py)): 各セリフの話し手、声か心の声か、コマに描く人物、所作のタグをだれに付けるか。
3. 読み取ったセリフの文面をそのまま使って台本にする。作画タグは、読み取った場面のタグ(構図が読めなければ寄り/引きから補う)。
4. 取り込んだ作品のコマ割りで物語を作り、コマの絵を生成してページに合成する。

- セリフの文面は文章モデルに返させません(書き換えさせません)。答えのセリフの数が合わないコマは、話し手を空にします。
- 文章モデルが決められなかったときは、話し手を空にし、描く人物は人数分を先頭から入れます。
- `make_images: false`(画面の「台本を作るところまでにする」)にすると、物語を作るところで止まります。物語のページでセリフや話し手を確かめてから、絵を生成できます。

## 4. API

| メソッド・パス | 内容 |
|---|---|
| `POST /api/manga-import` | 取り込む。`{title, files, use_vision, purpose, auto_manga}`。`purpose` は `similar`(既定)か `rebuild`。`auto_manga` を付けると、読み取りに続けて漫画を作る(`similar` なら似た漫画、`rebuild` なら作り直し) |
| `GET /api/manga-import`、`GET /api/manga-import/{id}` | 一覧、中身(`analysis.pages[].panels[]`) |
| `GET /api/manga-import/{id}/job` | 読み取り・生成の進み具合 |
| `POST /api/manga-import/{id}/analyze?use_vision=&purpose=` | 読み取り直す。`purpose` を付けると使い方を変える。手直ししたセリフは消える |
| `PUT /api/manga-import/{id}/pages/{page}/panels/{panel}/lines` | セリフを手直しする(`rebuild` のみ)。`{lines: ["…", "…"]}` で、そのコマのセリフを置き換える |
| `POST /api/manga-import/{id}/similar` | 似た漫画を作る |
| `POST /api/manga-import/{id}/rebuild` | 作り直す(`rebuild` のみ) |
| `DELETE /api/manga-import/{id}` | 取り込みとページ画像を消す |

`similar` / `rebuild` / `auto_manga` の本文: `{character_ids, genre, max_pages, color, references, make_images}`。

コマ(`panels[]`)の形:

```json
{
  "box": [40, 40, 720, 540], "people": 2, "shot": "medium", "text_blocks": 2, "role": "", "emotion": "",
  "detailed": true,
  "scene_tags": ["hallway", "school"], "action_tags": ["arm hug", "blush"], "cast_tags": ["1girl", "1boy"],
  "lines": [{"chars": 12, "ending": "問いかけ", "polite": true, "text": "…", "box": [500, 100, 560, 260]}]
}
```

`text` と `box` は `rebuild` のときだけ入ります。

## 5. 既知の制限

- **効果音(描き文字)は読めません。** 作り直しでも、効果音は台本に入りません(物語のページで足せます)。
- **話し手は文章モデルの推定です。** 口調や流れから決めるので、外れることがあります。
- **人物は多い順に2人まで**を、見た目から作ります。3人以上が出る作品では、使うキャラを選んでください。
- **吹き出しの位置は写しません。** 合成のときに置き直します。
- **所作の割り振り**: 2人以上のコマで、文章モデルが割り振らなかった所作は付きません。
- **取り込んだページは `data/imports/` に置き、公開しません。** 取り込みを削除すると、ページ画像も消えます。
