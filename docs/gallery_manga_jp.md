# ギャラリーの画像から漫画を作る

ギャラリー(`/gallery`)で選んだ画像をもとに、漫画を作る機能です。選んだ画像 **1枚が1コマ** になり、指定したジャンルに
合う話・セリフ・描き文字が付きます。

## 使い方

1. ギャラリーで「選択」を押し、コマにしたい画像を **コマにしたい順に** 選びます(24枚まで。4コマで1ページ)。
2. 下の選択バーの「漫画を作る」を押します。
3. ダイアログで決めます。
   - **ジャンル**: 漫画ドラフトと同じ候補から選ぶか、自由に書きます。話・セリフ・描き文字と、絵の手直しをこれに合わせます。
   - **話の方向・補足**(任意): 「待ち合わせに遅れて慌てる話」のように書くと、その方向で話を作ります。
   - **タイトル**(任意): 空なら自動で付きます。
   - **カラーで描く**: オフなら白黒。
   - **台本(物語)を作るところまでにする**: コマの絵を生成せず、物語のページでセリフやタグを確かめてから生成できます。
4. 進み具合は処理状況のダイアログに出ます。できあがると、「本棚で読む」「物語のページで手直しする」のリンクが出ます。

## 何が起きるか

| 段階 | 内容 |
|---|---|
| プロンプトを読む | 画像に埋め込まれた NovelAI の設定(本体とキャラごとのプロンプト)を読む。無ければ、ギャラリーの記録のプロンプト |
| コマのプロンプトにする | 強調の書き方(`1.3::tag::`、`{tag}`)を外し、品質・絵柄のタグ(`masterpiece`、`no text` など)と、出さない指定(`-1::tag::`)を除く |
| 話とセリフを考える | 文章モデル(NovelAI の GLM)に、ジャンルと各コマのプロンプトを渡し、全体で1つの話になるように、コマごとのセリフ(0〜2個)・描き文字(0〜1個)・ナレーションを考えさせる |
| 絵を手直しする | 文章モデルが、ジャンルと話に合うように、表情・動作・小物のタグを足し(6個まで)、合わないタグを外す。**人数と、髪・目・服などの見た目のタグは外させない**(だれの絵かが変わらないように) |
| 物語を作る | 台本から物語(1シーン=1コマ)を作る。以降は、ほかの漫画と同じように物語のページで手直しできる |
| コマを生成して合成する | 各コマを生成し直し、吹き出し・描き文字を合成してページにする |

- **選んだ画像そのものは使いません。** コマの形と漫画の絵柄にそろえるため、プロンプトから似た絵を生成し直します。
  シード値も変わるので、元の画像と同じ絵にはなりません。元の画像は変わりません。
- **プロンプトの無い画像は外します。** 拡大しただけの画像など、何を描くか分からないものです。外した枚数は結果の知らせに
  出ます。選んだ画像がすべてそうなら、作らずにエラーにします。
- **文章モデルが答えられなかったときは、絵だけの漫画になります**(セリフなし)。物語のページで足せます。
- 絵の内容は、ほかの漫画と同じ決まり(コンテンツガード)に従います。

## API

| | |
|---|---|
| `POST /api/gallery-manga` | 作り始める。`{image_keys, genre, theme, title, color, make_images}`。`image_keys` はギャラリーの画像のキー(選んだ順)。処理の状況(`{id, status, message, progress, total, detail, story_id}`)を返す |
| `GET /api/gallery-manga/jobs/{id}` | 進み具合。`status` が `done` なら `story_id` に物語のID、`error` なら `detail` に理由 |

## 既知の制限

- **話し手は付きません。** 登録済みのキャラを使わないので、吹き出しのしっぽは近い顔へ向きます。
- **キャラごとのプロンプトは、1つにつなげて使います。** 2人以上の画像では、見た目や動作が人物の間で混ざることがあります。
- **同じ人物を別々の画像から選んでも、コマごとに顔が少し変わります。** キャラ参照は使っていません。そろえたいときは、
  キャラシートを作って物語のページで割り当ててください。
- **コマの形は4コマの枠に合わせます。** 元の画像の縦横比とは変わります。
