## 監査サマリー

**2026-05-09** に、`novelai-sdk` 依存関係およびこのリポジトリのリレーサーバー（`src/python/`）を対象とした内部セキュリティ監査を実施しました。

**結果: セキュリティ上の問題は見つかりませんでした。**

---

## ネットワーク通信

SDK は以下の公式 NovelAI エンドポイントとのみ HTTPS で通信します。

| ホスト | 用途 |
|---|---|
| `https://image.novelai.net` | 画像生成 |
| `https://text.novelai.net` | テキスト生成 |
| `https://api.novelai.net` | 汎用 API |

サードパーティへのデータ送信は一切行いません。3つのベース URL はいずれも環境変数（`NOVELAI_IMAGE_BASE`、`NOVELAI_TEXT_BASE`、`NOVELAI_API_BASE`）で変更可能で、デフォルトは公式 NovelAI ドメインです。

### リレーサーバーのトポロジー

```
ブラウザ
  ↓ HTTP（localhost:8000、ローカルのみ）
リレーサーバー（src/python/）
  ↓ HTTPS
image.novelai.net  ← 公式 NovelAI サーバー
```

リレーサーバーはローカルマシン上のみで動作し、外部へデータを公開しません。

## 認証

- API トークンは標準的な `Authorization: Bearer {token}` ヘッダーとして渡されます。
- トークンはディスクへの書き込み、ログ出力、リクエストボディや URL への含め込みは一切行われません。
- `NOVELAI_API_KEY` / `NOVELAI_API_TOKEN` 環境変数（または `.env` ファイル）から読み込まれ、メモリ上のみで保持されます。

## 複数ユーザー(`APP_MODE=multi`)

招待した何人かで 1 つのサーバーを使うとき:

- **ログインできる人**: `scripts/manage_users.py add` で招待したメールアドレスだけ。メールアドレスはそのまま保存せず、
  `APP_MASTER_KEY` から作った鍵の HMAC だけを持つ。
- **本人かの確かめ**: ログインには NovelAI のメールアドレス・パスワードと、novelai.net のアクセストークンを使う。サーバーは、
  そのトークンの keystore がメールアドレスとパスワードから作った鍵で開けるかを確かめる。パスワードは保存しない。
- **ブラウザに置くもの**: `HttpOnly`・`SameSite=Strict` のセッションの Cookie だけ。NovelAI のトークンと keystore の鍵は
  ブラウザに渡さず、ブラウザから来た `Authorization` は捨てる。ほかのサイトからの書き込みは断り、CORS は
  `APP_ALLOWED_ORIGINS` の配信元だけ。
- **サーバーに置くもの**: NovelAI のトークンと keystore の鍵は、利用者ごとの鍵(PyNaCl の `SecretBox`)で暗号化し、その鍵を
  `APP_MASTER_KEY` で包む。マスター鍵はリポジトリに入れない(ホスティングでは Secret Manager)。なくしたり変えたりすると、
  招待も利用者も見分けられなくなる。
- **分離**: 利用者ごとに DB とフォルダを分ける。利用者が決まらないまま利用者のデータを開こうとすると、共有のデータに
  頼らずに失敗する。運営者の `.env` のトークンを、ほかの人のリクエストに使うことはない。
- **管理**: 管理ページ・`.env` を見ること・コンテンツガードの変更は管理者だけ。`.env` は画面からは書き換えられない。
- **監査ログ**: ログイン(断ったものも)・トークンの変更・管理とガードの変更・スクリプトの操作を、メールアドレスや
  トークンを入れずに残す(`scripts/manage_users.py audit` か管理ページ)。
- **利用上限**: 運営者の GPU(Ollama / vLLM)と ComfyUI に、利用者ごとの 1 日の回数と「同時に 1 つ」をかける。
- **バックアップと削除**: `scripts/manage_users.py delete` はサーバーからその人のデータを消す。それより前のバックアップに
  入っている分は、古いバックアップが片付くまで残る。

## コード検査

`novelai-sdk` において以下の危険なパターンを検索しましたが、**いずれも見つかりませんでした。**

- 動的コード実行: `eval()`、`exec()`、`compile()`、`__import__()`
- シェルアクセス: `subprocess`、`os.system()`、`popen()`
- 難読化コードや不審なインポート

ファイル I/O は、ユーザーが指定した画像ファイルの読み込みと、CLI 経由でユーザーが指定した出力ディレクトリへの生成画像の書き込みのみに限定されています。

## 認証情報の取り扱い

- API トークンは `.env` にのみ保存してください。ソースファイルにハードコードしないでください。
- `.env` は `.gitignore` に記載されており、リポジトリにコミットされません。
- `.env` やその内容を公開しないでください。
