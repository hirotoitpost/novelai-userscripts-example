## 目的

体の 3D(Hunyuan3D-2mv で作り、骨・形状パーツを入れたもの)に、衣装の服を着せる作り方を決める。

- A: 素体の正面・横・後ろの絵に服を描き足し、同じ Hunyuan3D-2mv で「服を着た体」を作って、体との差で服を切り出す。
- B: StdGEN で、服を着た正面の絵 1 枚から、体・服・髪を分けた 3D を作る。

## 対象データ

- 矢野栄子(キャラ 68)の裸の素体(素体 3)。体の 3D は作ってある。
- 衣装: タグで書いた、ブラウスと長いフレアスカート(体からはなれる服を見るため)。

## 比べる点

- 服の形が絵に合うか(スカートの広がり・袖・えり)
- 体と服の分かれ方(体が服から突き抜けないか・服に穴が無いか)
- 今の体・骨に付けられるか(大きさ・位置・姿勢)
- 髪が分かれるか
- 時間・GPU メモリ・Anlas

## 結果

### 服を着せた絵(A・B 共通の元)

- 素体の正面・横・後ろの首から下を、衣装のタグ(白いブラウス・ふくらんだ半袖・紺のフレアの長いスカート・黒い靴)で
  描き直した(インペイント)。
- 1 回目: 横の絵で、スカートの上に性器が透けて描かれた。裸の素体の体のタグに性器のタグ(pussy, clitoris)が入っていて、
  それを服を着せるプロンプトにも入れていたため。裸のときだけのタグを外した。スカートも体に沿う細いものになった
  (描き直す範囲が体のまわりだけ)ので、腰から下の範囲を台形に広げ、描き直しの強さを 0.95 にした。
- 3 回目で使える絵になった(Anlas 9 枚ぶん。2 回目はタグの検査で止まった)。正面はプリーツの A ライン。横・後ろは
  広がりが小さい。

### A: 着せた絵から Hunyuan3D-2mv で作り、服を切り出す

- 形: L4 で 197 秒。ブラウスのふくらんだ袖・えり・プリーツのスカート・靴まで、絵どおりに出た。
- 切り出し: 次の順に試した。
  1. 体の 3D との距離(外へ出た所 = 服): 着た体の形の、服の下の体(胸・お尻)は裸の体より小さく作られ、ぴったりした
     ブラウスは体の中に入る。距離だけでは分けられない。2 つの形は、頭とひじから先で重ねた(ICP。大きさ 1.009 倍)。
  2. 絵の色(肌の色から離れた所 = 服): 白いブラウスが肌の色に近く拾えない。影の腕を服にした。使えない。
  3. see-through の層を 3D に写す: 正面は良い(ブラウス・スカート・顔・脚・髪)。ただし see-through は素肌の腕・脚を
     handwear・legwear に入れ、ふくらんだ袖を handwear に入れた。横・後ろの絵ではスカートの層が出なかった。
     横の絵は左右の腕を分ける処理で失敗し、分けない設定で通した。PSD は絵の長い辺を画面に合わせて真ん中に置くので、
     その所を切り出して重ねる。
  4. 3 に、前から見えない所だけ「体より 15mm 外 = 服」(ひじから先は除く)を足し、となりの多数決でならした。
- 体の 3D に着せた: 前から見るとブラウスとスカートが体に合う。体に沈んだ所(5,801 頂点)は体の面の 3mm 外へ出した。
  横・後ろには、服と判定できなかった大きな穴が残る(横・後ろの see-through の層が足りない所)。

### B: StdGEN

- Colab の準備に手間がかかった(Python 3.9・torch 2.1 を前提にしている)。直した所は
  `notebooks/model3d_trial_stdgen_colab.ipynb` に入れた: 入れる先の Python をはっきり指定、torch は CUDA 12.1 版、
  CUDA 12 の nvcc を別に入れる(Colab の CUDA は 13)、setuptools<70・pymeshlab 2022.2.post4・trimesh<4、
  matplotlib の設定を Agg。
- A100 で、A ポーズに直す 76 秒(9.2GB)・多視点 581 秒(29.3GB)・粗い形 157 秒(20.4GB)・仕上げ 801 秒(9.6GB)。
  合わせて約 27 分。多視点の段は L4(24GB)には入らない。
- 体・服・髪が別のメッシュで出る(髪 8 万頂点・服 55 万頂点・体 38 万頂点)。分かれ方はきれい。
- ただし形が絵から離れる: ブラウスとスカートが 1 枚のワンピースになり、プリーツ・ふくらんだ袖・えりが消えた。
  髪はおだんごが消えて短いボブになった。体は標準的な体型で、矢野栄子の体(胸・お尻)と合わない。腕を開いた
  A ポーズなので、今の体(腕を下ろした姿勢)に付けるには姿勢と体型を合わせ直す必要がある。
- 重みは研究用。

### 比べて

| | A(着せた絵 + Hunyuan3D-2mv) | B(StdGEN) |
|---|---|---|
| 服の形が絵に合うか | 合う(袖・えり・プリーツ) | 合わない(1 枚のワンピースに) |
| 今の体・姿勢に付けられるか | そのまま重なる(同じ作り方・姿勢) | 体型・姿勢が違い、合わせ直しが要る |
| 体と服の分かれ方 | 難しい(see-through の層を写す + 形の規則。横・後ろに穴) | きれい |
| 髪 | 体の形の一部(層で分けられる) | 別のメッシュ(形は崩れる) |
| 時間・GPU | 197 秒・L4 | 約 27 分・A100(29GB) |
| Anlas | 衣装ごとに 3 枚 | 着せた正面の 1 枚(A と共用) |
