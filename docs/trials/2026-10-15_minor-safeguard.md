# 試行記録: 未成年キャラの安全対策(性的な場面に成人でないキャラがいれば止める)

- 日付: 2026-10-15
- ブランチ: `feat/minor-safeguard`
- 状態: **試行**(どこで止まったかを管理ページの記録で見て、扱いが適切か確かめる)

## 目的

漫画の流れ(コマの生成・おまかせ漫画・物語の自動漫画化・ギャラリーからの漫画・挿絵)は、キャラの年齢を見ていなかった。
性的なタグがあれば、キャラが誰でもそのまま描いていた。成人向けのタグ付けも「All characters are adults.」の前提で、
本文に女子高生と書かれていても性的なタグを付けていた。

## 決めたこと(ユーザーと)

| 項目 | 決めたこと |
|---|---|
| 止める定義 | 定義してあれば止める。キャラシートの年齢区分と、未成年を示す語(管理ページで指定) |
| 未定義のキャラ | 扱いはパスワード付きの管理項目。選べるのは「止める」(既定)と「全年齢で描く」。「成人として扱う」は選べない |
| パスワード | 守りを緩める変更だけに要る。はじめの値に戻す・強める変更には要らない。DB に scrypt の値だけを置く(.env には置かない) |
| パスワードを忘れたとき | この PC で `scripts/reset_guard_password.py`(画面からは消せない) |
| 書き出し・取り込み | ガードプロファイルも含める。取り込む前に違いを見せ、緩める項目はパスワードを聞く |
| はじめの値に戻す | 欄の上に置き、確認は1回 |

## キャラの年齢

| 区分 | 条件 |
|---|---|
| 未成年 | キャラシートで未成年と定義した。または手がかりがある(手がかりは成人の定義より優先) |
| 成人 | キャラシートで成人と定義し、手がかりが無い |
| 未定義 | どちらでもない |

手がかり:

- キャラシートの未成年を示すタグ(`dataset.minor_tags`)
- キャラのメモ・物語の本文とメモリで、キャラの名前と同じ文にある未成年を示す語(`story.minor_words`。女子高生・中学生・〇歳(17以下)など)

## 止める場所

| 場所 | 扱い |
|---|---|
| 漫画のコマ(v2) | 性的な場面(場面のタグかキャラの動作のタグ)に未成年がいれば描かない。前に描いたコマも合成に使わない。未定義のキャラか、キャラが割り当てられていない場面は、設定に従って止めるか全年齢で描く |
| 状態の描き直し(透明 など) | コマと同じ判定 |
| 挿絵(v1、ページごと) | ページのどれかの場面が止まれば、ページごと描かない |
| 成人向けのタグ付け(分割・付け直し) | 本文・メモリに未成年を示す語があれば、全年齢のタグ付けにする |

緩める変更でパスワードが要るもの: 止める語を減らす、未定義のキャラの扱いを変える、未成年の定義を外す(成人にする・別名で
外す・キャラを消すも含む)、ガードプロファイルの語を減らす・消す。

## 確かめたこと

- テスト(`tests/test_guard_safety.py`)
  - 年齢の判定と、場面の判定
  - 強める変更と緩める変更の見分け
  - パスワードの設定・変更・続けて間違えたときの待ち
  - 書き出しと取り込み
  - キャラシートの年齢区分
  - コマの生成で止めること(前のコマも外す)
  - 成人向けのタグ付けを断ること
- 画面(DB の写しで動かした別のバックエンドに、スマホ幅でつないだ)
  - パスワードの設定前に緩める変更をすると、止まる
  - 設定後は、パスワードを聞く画面が出て、入れると保存できる
  - 書き出し → はじめの値に戻す → 取り込みで、違いの一覧が出て取り込める
  - キャラの年齢区分の一覧

## 試しているときに見つけた問題

- 漢数字の範囲 `[一-九]` は、文字の番号が並んでいないので「二」「八」などを含まない。漢数字は1つずつ並べて書いた。
- 未成年を示す語は、名前と同じ文にあるときだけそのキャラの手がかりにする。本文のどこかにあるだけで全員を未成年とすると、
  回想の「小学生の頃」などで成人キャラまで止まるため。成人向けのタグ付けは物語全体で見るので、本文のどこかにあれば止める。

## 残っている課題

- 生成した絵が幼く描かれていないかは、まだ確かめていない(判定モデルで child などを見る案)
- 登場人物の抽出で、文章モデルに年齢層を根拠付きで答えさせる案は、まだ入れていない
- 成人向けの取り込み作品を、成人でないキャラの漫画の構成の参考にすることは、まだ止めていない
- 前に作った物語(98・99・129 など)の扱いは、ユーザーが決める
