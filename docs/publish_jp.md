# 出版(パブリッシュ)

ギャラリーで選んだ画像や、本棚で選んだ本を、NovelAI の生成情報(メタデータ)を取り除いた「出版物」として別に保存し、ZIP にまとめる機能です。外へ出す前の仕上げとして使います。

このアプリがするのは、手元で出版物(ZIP)を作るところまでです。外部のサイトへの投稿・アップロードはしません。

## 1. 使い方

出版は、一覧からまとめて行うことも、アイテムを表示した画面からそのまま行うこともできます。

| 場所 | 操作 |
|---|---|
| ギャラリー(`/gallery`)の一覧 | 「選択」→ 画像を選ぶ →「出版する」 |
| ギャラリーの画像の表示画面 | 「出版する」(その1枚をそのまま出版)/「出版に選ぶ」(ほかの画像とまとめるために選ぶ) |
| 本棚(`/bookshelf`)の一覧 | 「選択」→ 本を選ぶ →「出版する」 |
| 本棚の本の表示画面 | 「出版する」(その本をそのまま出版)/「出版に選ぶ」 |
| 出版物(`/publications`) | できた出版物の一覧。ZIP のダウンロードと削除 |

表示画面の「出版に選ぶ」は、一覧の「選択」と同じ選択に入ります。表示画面を閉じると選択バーが出ていて、そこから「出版する」を押せます。もう一度押すと選択から外れます。

### 出版のダイアログ

「出版する」を押すと、ダイアログが開きます。

- **出版物の名前** — ZIP の名前になります。
- **作成後に ZIP をダウンロードする** — オンにすると、出版物ができたあと、そのまま ZIP をダウンロードします。オン・オフは端末ごとに覚えます(`localStorage` の `nai_publish_download`。既定はオフ)。

オフのまま出版したときは、できあがりの知らせに「ZIP をダウンロード」のボタンが出ます。あとからでも、出版物のページでダウンロードできます。

## 2. 取り除くもの

NovelAI の画像には、生成の設定(プロンプト、ネガティブプロンプト、シード値、モデル、サンプラーなど)が2か所に入っています。出版物では両方を取り除きます。

| 入っている場所 | 取り除き方 |
|---|---|
| PNG のテキスト(`Comment`、`Description`、`Source`、`Software` など) | 画素だけを新しい画像に写す。テキスト・EXIF・ICC などの付属情報は持ち越さない |
| アルファチャンネルの最下位ビットに隠した埋め込み(Stealth) | アルファチャンネルを捨てる |

- **絵の色は変えません。** NovelAI の画像のアルファは 254 か 255 だけなので、アルファを捨てるだけにしています(白地に重ねると、アルファが 254 の画素の色が 1 だけ変わるため)。本当に透明な部分がある画像だけ、白地に重ねます。
- 出版物の画像は、アルファなしの PNG(RGB)になります。
- **取り除いたあとに確かめます。** できた画像をもう一度読み取り、生成情報が残っていれば、その出版物は作りません(エラーになります)。

ファイル名も付け直します(`001.png`、`002.png`…)。元のファイル名(履歴の ID など)は出版物に入りません。

## 3. 保存される場所

元の画像・本は変えません。出版物は別の場所に保存します。

```
outputs/publications/pub_<ID>/
├── files/            ← 生成情報を取り除いた画像
│   ├── 画像/001.png …
│   └── <本の題>/001.png …
└── <出版物の名前>.zip  ← files/ の中身をまとめたもの
```

- 選んだものが1つのまとまりだけ(画像だけ、または本1冊だけ)のときは、フォルダに分けず、`001.png`… を直に入れます。
- 画像は、選んだときに表示していた並びの順に番号が付きます。本は、漫画のページ順です。
- 漫画のページが無い本(文章だけの本)は、本文を `本文.txt` として入れます。
- 出版物はギャラリーには出ません。`outputs/` は Git の管理外です。
- 出版物を消しても、元の画像・本は消えません。

記録は DB のテーブル `publications` に持ちます(題、保存先、ZIP の場所と大きさ、ファイル数、入れたもの、作成日時)。

## 4. API

| メソッド・パス | 内容 |
|---|---|
| `POST /api/publications` | 出版物を作る。`{title, image_keys: [...], book_ids: [...]}`。`image_keys` はギャラリーのキー、`book_ids` は物語の ID |
| `GET /api/publications` | 一覧(新しい順) |
| `GET /api/publications/{id}/download` | ZIP |
| `GET /api/publications/{id}/cover` | 1枚目の画像 |
| `DELETE /api/publications/{id}` | 出版物を消す |

- 1回に入れられるのは、画像 1000 枚、本 50 冊までです。
- 見つからない画像・本は飛ばします。1つも見つからなければ 404、入れられるファイルが無ければ 422 です。
- 生成情報を取り除けなかったときは 500 を返し、作りかけの出版物は残しません。

処理の中身は [src/python/publish.py](../src/python/publish.py)、API は [src/python/routes/publish.py](../src/python/routes/publish.py) です。

## 5. 既存の「zip でダウンロード」との違い

| | ギャラリーの「zipでダウンロード」・本棚のダウンロード | 出版する |
|---|---|---|
| 生成情報 | **残る**(元の PNG のまま) | **取り除く** |
| 保存 | しない(その場でダウンロードするだけ) | `outputs/publications/` に残る |
| 用途 | 自分用の持ち出し・バックアップ | 外へ出す前の仕上げ |

## 6. 既知の制限

- **取り除くのは、画像に埋め込まれた情報だけです。** 絵そのものに描かれた文字や署名は変わりません。
- **漫画のセリフや本文はそのまま入ります。** 内容の確認はしません。
- **PNG だけを作ります。** JPEG や PDF での出版には対応していません。
- **成人向けかどうかは区別しません。** 選んだものをそのまま入れます。
